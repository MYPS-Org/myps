Philippine region display boundaries

Source: https://github.com/faeldon/philippines-json-maps (James Faeldon, MIT; see LICENSE.txt).
Downloaded 2026-09-09 from the 2023 GeoJSON country/lowres and regions/lowres datasets.
NCR uses the country/medres geometry for closer zooms. Coordinates rounded to five decimal places.

Display adaptations:
- Negros Occidental, Negros Oriental and Siquijor province geometries grouped as NIR and removed from VI/VII (RA 12000).
- Sulu province geometry moved from BARMM to Region IX (EO 91, 2025).
- Unused area/length properties removed. Province components retained as MultiPolygon parts.

These are simplified display outlines derived from a 2023 geometry snapshot, not survey boundaries or historical boundary versions. Budget percentages come exclusively from dashboard project data.
