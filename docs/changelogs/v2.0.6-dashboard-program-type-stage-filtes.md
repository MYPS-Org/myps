# MYPS changes since v2.0.5-fix-modi-component-auto-fill-and-batch-confirm-program-name

## Dashboard: Program Type and Program Stage Name filters, per-program KPI details, steadier reloads (#256)

- The dashboard title "National Expenditure Program & Portfolio Matrix" is now **Program Stage**. The line under it names the stage the figures cover (for example, NEP-E · National Expenditure Program with Errata) or shows "All budget stages".
- **New Program Type and Program Stage Name filters** sit beside Category (Live DB only). Every section narrows by Category, type and stage together. Only the nine budget stages are offered, and the region map badge follows the chosen stage.
- **KPI details list projects per program.** In FY Infrastructure Budget, Active Portfolio and Publication Compliance, each program shows its name, stage, "N of M projects" and FY amount, and the programs add up to the card.
- Expanding a program shows its projects in the same columns as Program Details. Projects no longer show their own amount, so a project's FY share is no longer compared with its multi-year total.
- **Clicking a project opens its details.** It opens Project Details for that stage, or the Lump Sum page for a Lump Sum Project. The Project ID is a link, so you can open it in a new tab.
- The For Publish and Published tabs show exact counts.
- In the KPI details, the table header no longer covers rows, stage badges stay on one line and descriptions show in full.
- The region tables list regions in the standard region order, and Northern and Southern Luzon now show their amount.
- The Annual Budget & LS trend prints each year's two amounts under its bars. Selecting a year no longer reloads or hides this chart.
- **The Project Stages box is now Project Categories.** Clicking a category applies the Category filter. The project list no longer filters by stage from this box.
- **The page stays in place while it reloads.** Sections keep their previous figures, dimmed and marked "Updating…", while a new year or filter loads. The element you clicked stays on screen until you scroll.
